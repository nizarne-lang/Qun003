الدرس الأول · البنود 1-1، 1-2، 1-3

مفهوم المجموعة وطرق التعبير عنها

ما المجموعة؟ وكيف نكتبها بطريقة السرد وبطريقة الصفة المميزة؟ ومتى نستخدم الرمزين ∈ و ∉؟

أهداف الدرس
  • أن يميّز الطالب بين العنصر والمجموعة ويستخدم الرمزين ∈ و ∉ استخداماً صحيحاً.
  • أن يكتب مجموعة معطاة بطريقة السرد (القائمة).
  • أن يكتب مجموعة معطاة بطريقة الصفة المميزة.
  • أن يوظّف المجموعات في تصنيف بيانات إدارية واقتصادية.

1-1 مقدمة: لماذا نبدأ بالمجموعات؟

الفرز والتصنيف عمليتان نمارسهما يومياً دون أن ننتبه. فالطفل يجمع كراته الملوّنة بناءً على اللون، ثم بناءً على النوع. وأنت اليوم في المستوى التحضيري تتعامل مع مجموعة المقررات التي تدرسها، ومجموعة القاعات التي ترتادها، ومجموعة المدرسين الذين يدرّسونك. كل هذه مجموعات.

وفي إدارة الأعمال والاقتصاد يتكرر الأمر ذاته: مجموعة العملاء، مجموعة الموردين، مجموعة المنتجات في المخزن، مجموعة الموظفين الذين يتقنون لغة أجنبية. ولهذا نبدأ الرياضيات من هنا.

1-2 مفهوم المجموعة

المجموعةالمجموعة هي تجمُّع من الأشياء الموضوعة سوياً والمحدَّدة تحديداً تاماً. ونستخدم عادةً الأحرف الكبيرة A, B, C, … للتعبير عن اسم المجموعة، وتُسمى الأشياء التي تتكون منها المجموعة العناصر.
شرط مهم: التحديد التام «مجموعة الطلبة الطوال» ليست مجموعة رياضية، لأن كلمة «طوال» غير محددة تحديداً تاماً. أما «مجموعة الطلبة الذين طولهم 175 سم فأكثر» فهي مجموعة، لأننا نستطيع الحكم على أي طالب: أينتمي إليها أم لا؟

1-3 طرق التعبير عن المجموعة

الحكم على علاقة عنصر بالمجموعة يُكتب بأحد رمزين:

a ∈ A  ⟵ العنصر a ينتمي إلى A
a ∉ A  ⟵ العنصر a لا ينتمي إلى A

1-3-1 طريقة السرد (القائمة)

نذكر جميع العناصر بين قوسين خاصين { } تفصل بينها فواصل، دون تكرار وبغض النظر عن الترتيب.

العدد 2233053  ⟸  A = {2, 3, 0, 5}
انتبه {1,2,3} = {3,1,2} = {1,1,2,3}  — الترتيب لا يهم، والتكرار لا يضيف عنصراً جديداً.

1-3-2 طريقة الصفة المميزة

نصف العناصر بصفة أو أكثر تحددها تحديداً تاماً:

B = { S :  S طالب في الفصل التحضيري للفصل الدراسي الحالي }
C = { P :  P جرم سماوي }

وفي الرياضيات نستعملها كثيراً مع الأعداد:

تعريف (1-1)نعبّر بالرمز ℕ عن مجموعة الأعداد الطبيعية:
ℕ = {0, 1, 2, 3, … }
A = {2n ; n ∈ ℕ} = {0, 2, 4, 6, …}
بالسردبالصفة المميزةمتى نفضّلها؟
{0,1,2,3,4}{n ∈ ℕ ; n < 5}العناصر قليلة ⟵ السرد أوضح
{0,2,4,6,…}{2n ; n ∈ ℕ}العناصر كثيرة أو غير منتهية ⟵ الصفة المميزة
يصعب سردها{x ; x عميل اشترى أكثر من 1000 ريال}الوصف الإداري ⟵ الصفة المميزة
